# Learning Monorepo

A repository for learning technologies.

## How to Use This Repo With Your AI Agent

This repo is designed to work with AI coding assistants. Here's the workflow:

### Initial Setup
1. **Open your AI agent** (GitHub Copilot, Cursor, Windsurf, etc.)
2. **Open this repository** in your IDE/editor
3. **Ask your AI agent** to read `AGENTS.md` first

### Example Prompts to Get Started

```
Read AGENTS.md and explain the teaching philosophy to me
```

```
I'm ready to start learning Rust. What should I do first?
```

```
Show me the Rust curriculum and help me understand what I'll learn
```

```
Take me to the first Rust lesson and explain what I need to do
```

### Typical Learning Flow

1. **Agent reads AGENTS.md** - Understands teaching philosophy
2. **Agent shows curriculum** - Explains what you'll learn
3. **Agent navigates to first lesson** - lesson-00-basics
4. **Agent explains exercise** - Shows you what to implement
5. **You write code** - Agent guides with questions, not answers
6. **Agent helps debug** - Points to errors, explains concepts
7. **Track progress** - Update progress.md as you complete lessons

## Notes

- Each topic maintains its own progress tracker: `learn/{topic}/progress.md`
- Update your progress after completing each exercise
- Don't skip ahead - each lesson builds on previous concepts
- Ask your agent to explain the "why" behind concepts, not just the "how"
